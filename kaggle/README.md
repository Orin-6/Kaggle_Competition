# 🚢 Titanic Survival Prediction

A Machine Learning classification project based on the **Titanic - Machine Learning from Disaster** Kaggle competition.

The objective of this project is to predict whether a passenger survived the Titanic disaster using passenger information and Machine Learning algorithms.

## 📌 Project Overview

This project covers the complete Machine Learning workflow, from data exploration and preprocessing to model training, evaluation, and Kaggle submission.

## 🎯 Project Objectives

- Explore and understand the Titanic dataset.
- Perform Exploratory Data Analysis (EDA).
- Handle missing values and clean the data.
- Apply feature engineering and categorical encoding.
- Build and evaluate classification models.
- Generate predictions for Kaggle submission.

## 🔍 Exploratory Data Analysis (EDA)

Performed analysis on:

- Survival distribution.
- Survival by gender.
- Survival by passenger class.
- Age distribution by survival.
- Survival by family size.
- Fare distribution.

## 🧹 Data Preprocessing

- Handled missing values in Age, Embarked, and Fare.
- Removed unnecessary columns.
- Applied categorical encoding.
- Prepared training and validation datasets.

## ⚙️ Feature Engineering

Created new features:

- `FamilySize`
- `IsAlone`
- `Title`
- `AgeGroup`

## 🤖 Machine Learning Models

Implemented the following classification algorithms:

1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier
